# 栏目与模板指南

## 映射表

| 栏目 | 模板文件 | 主要阅读任务 |
|---|---|---|
| 文章解读 | `assets/templates/01-research-explainer.md` | 准确理解一篇研究 |
| 学术前沿 | `assets/templates/02-frontier-tutorial.md` | 学会一种方法、模型或研究工具 |
| 会议通知 | `assets/templates/03-notice-opportunity.md` | 判断是否参会、投稿及如何行动 |
| 特刊推荐 | `assets/templates/03-notice-opportunity.md` | 理解主题范围、资格、时间与投稿方式 |
| 广纳英才 | `assets/templates/03-notice-opportunity.md` | 判断岗位或招生匹配度并申请 |
| 新近动态 | `assets/templates/04-association-news.md` | 快速理解事件、意义和后续行动 |
| 学会历史 | `assets/templates/05-history-profile.md` | 理解人物、阶段、证据和历史意义 |

五套模板是结构骨架，不是固定作文。允许删去确实不适用的小节，但不得省略对应栏目的必填事实。正文规模、分栏目展开要求和统一品牌页脚必须同时遵循 `references/editorial-depth-and-footer.md`。

## 1. 论文解读

必填：中英文题名、期刊、作者、SDGs（若能可靠判断）、研究问题、数据与方法、核心结论、贡献、稳健性/异质性/限制、实践意义、未来研究、来源。

写作重点：先解释为什么值得研究，再给出可核实的具体结果。引用表图或公式时必须核对编号和含义。不能只转述摘要。

建议长度：正文通常2800—4500字；严格模式不低于2400字。现有 `prompts.txt` 是最低展开起点，不是上限。不得用重复表达凑字数。

## 2. 方法科普

必填：问题场景、直觉解释、核心假设、步骤或代码、与相近方法的差异、适用场景、限制、复现信息。

写作重点：示例和类比服务于准确理解。代码必须能运行或明确标记为伪代码。不要把模型名、论文名或软件功能混为一谈。

## 3. 通知机会

根据子栏目保留字段：

- 会议通知：主办方、主题、时间、地点/形式、重要嘉宾、征稿范围、截止日期、费用、注册/投稿方式、联系人。
- 特刊推荐：期刊、专题名、客座编辑、范围、关键日期、投稿链接、稿件类型和特殊要求。
- 广纳英才：机构、岗位/项目、职责、资格、合同或资助信息、截止日期、材料、申请链接、联系人。

所有日期、费用、链接和联系信息都属于高风险事实。若来源不是官方页面，状态至少为 `WARN`。

## 4. 学会新闻

必填：事件导语、时间地点、参与者、发生了什么、为何重要、关键成果、后续安排、来源。

写作重点：先事实后评价。荣誉、排名、指标和“首次”等表述需要官方依据。避免把宣传口号写成事实判断。

## 5. 历史人物

必填：叙事开场、人物/时期背景、时间线、关键事件、原始证据或可追溯来源、与 CEA 的关系、历史意义、资料边界。

写作重点：区分回忆、档案、转载和作者解释。对记忆性材料使用“据某某回忆”等限定语，不把回忆写成唯一历史事实。

## 栏目判断

- 以单篇论文的研究问题与发现为核心：文章解读。
- 以方法、模型、代码、教程或研究工具为核心：学术前沿。
- 以明确时间、地点、投稿、注册或参会行动为核心：会议通知。
- 以学会已发生事件、奖项、合作或期刊动态为核心：新近动态。
- 以历史阶段、口述史或人物回忆为核心：学会历史。
- 以专题征稿及研究议题为核心：特刊推荐。
- 以岗位、导师、招生或人才项目为核心：广纳英才。

内容跨栏目时选定一个主栏目，在 `sources.md` 记录次级标签，不混合两个完整模板。
