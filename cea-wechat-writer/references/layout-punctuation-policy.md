# 图表图注与表格换行标点

## 图表图注

图和表的可见图注不使用任何标点，不只是删除句号。图号或表号后直接空一格接说明；说明内部也不用冒号、逗号、顿号、括号、连接号或其他标点。需要列举时改用自然语序以及“与”“及”等连接词。

是否显示图注必须逐项向用户确认，不得根据模板自动决定。图和表分别记录 `caption-decision` 或 `table-caption-decision`：`user-confirmed-add` 表示显示经用户确认的图注，`user-confirmed-omit` 表示不显示图注。

正确：

```markdown
_图1 ESG表现通过全要素生产率与研发投入影响企业价值的研究框架_
<!-- caption-decision: user-confirmed-add -->

_表1 不同样本组的主要回归结果_
<!-- table-caption-decision: user-confirmed-add -->
```

错误：

```markdown
_图1：ESG、全要素生产率与企业价值。_

_表1 不同样本组的主要回归结果。_
```

用户选择不添加表格图注时，在表格前保留：

```markdown
<!-- table-caption-decision: user-confirmed-omit -->
```

图注来源仍按 `references/image-policy.md` 写在下一行隐藏批注中，不计入可见图注。

## 表格单元格换行

换行本身不决定是否使用标点。先判断换行前后的每一项是什么：

- 单个词、短标签、姓名、机构名、日期、数字、单位或并列短语：不加标点
- 完整陈述句：按正常阅读需要使用句内和句末标点
- 同一单元格内的并列标签：各行保持相同句法形态，通常都不加标点
- 同一单元格内的多句说明：每句正常使用标点，不能为了视觉整齐删去必要标点

正确：

```markdown
| 类型 | 内容 |
|---|---|
| 研究方法 | 固定效应<br>工具变量<br>稳健性检验 |
| 注意事项 | 截止时间以官网为准。<br>逾期材料不予受理。 |
```

交付前逐个检查含 `<br>`、`<br/>` 或单元格内换行的表格：如果一行只是一个词或短标签，删除末尾标点；如果是一句完整的话，保留符合该语言阅读习惯的标点。
