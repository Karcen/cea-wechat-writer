# Skill 与模型训练路线

## 当前阶段：Skill 优先

当前历史材料适合做：

- CEA 栏目路由与五套结构模板；
- 同栏目范文检索；
- 科学语言、来源台账、图片顺序和二次检查规则；
- 公众号 Markdown 的稳定输出格式。

当前材料不适合直接承担完整监督微调，因为大多数是成稿，没有保存同一任务的原始输入、模型初稿、人工修改和修改理由；乱码 HTML 也不能进入语言训练集。

## 每次任务应沉淀什么

只有用户明确同意归档时，保存：

1. 原始输入文件清单及哈希；
2. 用户选择的语言、栏目、审核方式和模板；
3. 模型生成的 `article.md`；
4. 作者确认后的终稿；
5. `sources.md` 与 `qa-report.md`；
6. 是否采用、主要修改类型和用户评价；
7. 图片来源与最终放置位置。

使用 `scripts/archive_revision.py` 建立不可混淆的任务记录。不要把不同文章段落拼成虚假的输入输出对。

## 何时考虑微调

满足以下条件后再评估：

- 每个主要栏目都有持续积累、来源可靠的真实任务；
- 终稿由作者确认，能区分事实修正、文风修正和排版修正；
- Skill 加检索后的常见错误已经稳定可测；
- 留出按文章和时间分隔的测试集，防止同一文章泄漏到训练和测试；
- 微调目标明确，例如“CEA中文语气与段落组织”，而不是让模型记忆动态事实。

即使微调，也继续保留来源检索、图片处理和 QA Skill。模型权重不应承担实时事实库或发布闸门的职责。

## 评估维度

- 事实一致性和来源覆盖率；
- 因果边界、样本边界和限制条件保留率；
- 错别字、语病和术语一致性；
- 栏目结构完成度；
- 图片相关性、位置和权利记录；
- 作者修改量与一次通过率；
- 用户强制通过的风险类型。
