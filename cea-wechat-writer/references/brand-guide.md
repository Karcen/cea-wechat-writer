# CEA 品牌基线

本基线来自当前 119 篇历史 HTML 的重复特征，只用于保持视觉和语气连续性，不代表永久品牌规范。

## 视觉元素

- 主强调紫：`rgb(122, 79, 214)` / `#7A4FD6`
- 辅助蓝：`rgb(0, 122, 170)` / `#007AAA`
- 正文深灰：`rgb(79, 79, 79)` / `#4F4F4F`
- 白底与克制留白
- 历史正文常见 15—17px、左对齐或两端对齐；Markdown 只保留语义层级，具体字号留给后续渲染器。

不要在 Markdown 中嵌入复杂 CSS。使用标题、粗体、引用、列表、分隔线、图片和图注表达层级。

## 语言元素

- 机构身份应体现学术共同体和公共传播责任。
- 保持专业、准确、友好；文章解读可以直观生动，但不娱乐化研究结论。
- 默认避免密集 emoji。通知类可少量使用日期、地点、行动提示符号，全文不超过必要程度。
- CEA 与 JCEBS 介绍优先使用经用户确认的当前版本。

## 动态事实

历史 HTML 中的期刊指标、主编名单、机构职务和二维码可能过期。即使它们在多篇文章中重复出现，也必须在发布前用官方来源核实。

## 固定结尾

Markdown 初稿不自动生成往期精彩文章、CEA/JCEBS介绍或关注提示。使用 `assets/templates/00-cea-standard-footer.md` 保留中英文复制提示和联合传播图片，由公众号编辑从已发布往期文章复制完整文字结尾。确需写入时逐字使用 `references/approved-fixed-ending-copy.md`。

## 品牌资产

- 使用前检查显示清晰度和实际跳转目标。
- 不重新绘制、裁切或添加覆盖层。
