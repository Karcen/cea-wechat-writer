# 历史语料使用指南

## 语料范围

- Word：13 篇编辑稿，含文章解读、学术前沿和会议预告；部分目录还包含对应论文 PDF、图表和音频。
- HTML：119 篇公众号页面，覆盖七个栏目。
- HTML 是完整微信页面保存件，包含脚本、往期导航、远程图片和动态页脚；部分正文存在 MacRoman 或 Latin-1 路径造成的乱码。脚本会尽量修复，但原文件已经写入替换字符的部分无法可靠还原。

## 构建清洁语料

在原始目录更新后运行：

```bash
python3 scripts/build_corpus.py \
  --word-dir /Users/karcenzheng/Downloads/CEA_Skill/train_by_Shijie_Word \
  --html-dir /Users/karcenzheng/Downloads/CEA_Skill/train_by_category_html \
  --output references/corpus
```

脚本不修改原始文件。它生成清洁文本、索引、样式统计和 Word/HTML 候选配对。

## 使用原则

- 优先检索同栏目、同任务和相近主题的 2—3 篇示例。
- 默认排除索引中标记为 `degraded_mojibake` 的正文；这些页面仍可参与颜色、字号、图片和版式统计，但不能作为语言范文。
- 默认不跨栏目返回范文。某栏目没有可用正文时，依靠该栏目的正式模板和科学语言规范；不要用无关栏目凑足示例数量。
- 示例只控制结构、语气、段落节奏和术语解释方式。
- 历史稿件是合格风格样本，但不是当前事实库。
- 反复出现的 CEA 页脚不计入正文长度，但属于成稿必需结构。语料索引保留页脚是否存在及其长度；生产稿统一使用 `assets/templates/00-cea-standard-footer.md`，并按当前官方来源核验动态字段。
- 语料中的远程图片只记录 URL，不自动宣告可复用权利。

## 为什么暂不微调

当前材料以“成稿”居多，稳定的“输入—生成稿—人工修改稿”监督对较少。先用检索、模板、证据台账和 QA 工作流可获得更可控的结果。持续保存用户实际修改后，再按栏目积累监督数据，评估是否需要语言风格微调。
