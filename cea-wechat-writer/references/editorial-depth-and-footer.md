# 正文深度与固定结尾规范

## 1. 为什么不能写成短摘要

CEA 公众号稿不是论文摘要、会议卡片或链接导语。正文必须完成三个任务：交代事实、解释背景、帮助读者理解或行动。除非用户明确要求短讯，不得用数百字概括代替完整成稿。

历史语料显示，各栏目通常通过多级标题、连续论证、图表或名单、行动信息和固定品牌页脚形成完整文章。篇幅只是最低质量信号；达到字数但没有证据、解释和结构仍不合格。

## 2. 最低正文规模

以下字数按中文汉字近似计算，不含 Markdown 标记、来源注释和固定品牌结尾。材料不足时不得注水；应停止扩写并把缺失信息列为 `BLOCK`，请用户补充来源。

| 栏目 | 常规目标 | 严格模式最低值 | 深度重点 |
|---|---:|---:|---|
| 文章解读 | 2800—4500字 | 2400字 | 问题、概念、数据方法、具体结果、贡献、检验、边界、实践和未来研究 |
| 学术前沿 | 2600—4500字 | 2200字 | 问题场景、原理、假设、步骤、实例、比较、适用条件、失败方式和复现 |
| 会议通知 | 1800—3500字 | 1500字 | 背景、主办方、主题、嘉宾、征稿范围、日程、费用、提交和联系信息 |
| 新近动态 | 2000—4000字 | 1700字 | 事件事实、主要环节、人物发言或成果、组织意义、后续安排 |
| 学会历史 | 2800—5000字 | 2400字 | 叙事开场、时代背景、时间线、史料、与CEA关系、历史解释和资料边界 |
| 特刊推荐 | 1800—3200字 | 1500字 | 学术背景、专题范围、适合的研究问题、编辑、日期、费用和投稿步骤 |
| 广纳英才 | 1800—3200字 | 1500字 | 机构与方向、岗位分层、资格、支持条件、材料、流程和联系人 |

历史短讯、纯图片集或只有一项更正的通知可以低于最低值，但必须由用户明确选择“短讯模式”，并在文章元数据写 `<!-- length-mode: short-brief-approved -->`。不得自动进入短讯模式。

## 3. 分栏目深度要求

### 文章解读

- “研究问题”约500字：解释现实背景、理论张力、核心概念与变量，不只复述摘要。
- “数据与方法”至少300字：交代样本、时期、变量、模型、识别逻辑和可比方法。
- “核心结论”至少500字：逐项写方向、效应、条件及对应图表或公式。
- “文章贡献”至少300字：与既有研究比较，区分作者主张与编辑判断。
- “稳健性、异质性与局限”至少350字：分别说明做了什么、发现什么、仍不能回答什么。
- “实践意义”至少350字：按政策制定者、企业、消费者或研究者分层讨论。
- “未来研究”至少200字：从已识别的边界自然推出，不写空泛展望。

### 学术前沿

先说明方法解决的具体困难，再解释正式原理。至少提供一个完整例子或可运行代码；若是伪代码必须标注。必须比较相近方法，并明确数据前提、核心假设、诊断方法、失败条件与复现环境。

### 通知、特刊与招聘

不得只列信息卡。先用背景段说明机会为何出现，再按读者决策路径展开：是否匹配、关键要求、需要准备什么、如何提交、何时得到下一步信息。对强时效字段逐项引用当前官方来源。

### 新近动态

至少完整还原两个以上事件环节；有发言材料时概括各环节的实质内容，不堆人名。编辑性意义分析必须与已确认事实分开，不用“圆满”“重磅”等词代替信息。

### 学会历史

用时间线组织材料，并把个人回忆、同期档案、转载说明和编辑解释分开。历史意义必须从已呈现的史料推出，不能用当代评价补齐史料空白。

## 4. 固定结尾

119篇HTML表明，往期精彩文章、CEA与JCEBS介绍以及关注图片构成稳定品牌结尾，但这些内容由公众号编辑从已发布往期文章复制，Markdown 初稿不自动生成。

1. Markdown 末尾只放中英文 HTML 注释，提醒编辑从已发布的往期文章复制完整固定结尾。
2. Markdown 不显示往期精彩文章标题和链接、CEA介绍、JCEBS介绍或关注提示。
3. 底部联合传播图片继续固定使用 `扫码_搜索联合传播样式-标准色版.png`。
4. 用户明确要求在 Markdown 中写入介绍时，必须逐字使用 `references/approved-fixed-ending-copy.md`，不得改写。

直接复制 `assets/templates/00-cea-standard-footer.md` 的结构。不得自行缩写为“经确认的CEA结尾说明”。

默认 Markdown 不使用 `S90`、`S91` 或 `S92`。只有用户明确要求写入核准固定结尾时，才登记相应来源。

## 5. 深度审校

交付前逐项回答：

- 每个二级标题下是否至少推进一个新事实、解释或行动信息？
- 结论是否对应具体表图、统计量、原文段落或官方字段？
- 是否说明了“为什么”，而不只是“是什么”？
- 是否同时写出适用条件和不能推出的结论？
- 图片是否承担证据、解释或节奏功能，而不是任意装饰？
- Markdown 是否没有自动生成固定结尾文字？
- 是否保留中英文复制提示和联合传播图片？
- 所有编辑提示是否只存在于中英文 HTML 注释？

任何一项无法回答时，不得用泛泛表述凑字数。
