# 杜一公众号 CSS 风格库

这不是临时 CSS 清单，而是微信发布排版流程中的稳定审美层。

使用时优先看文章场景，再选风格；不要只因为用户提到某个品牌就机械套用。

## 正式风格池

这 16 个中文意象风格是正式公众号流水线主线，已进入 `duyi-wechat-paipan/scripts/render_wechat_html.py`，可以直接作为 `--style` 参数生成 WeChat-ready HTML。

| style id | 审美公式 | 适合 |
|---|---|---|
| 白瓷 | 白瓷釉面 + 留白克制 + 微阴影 | 品牌主张、产品介绍、高级短文 |
| 蓝图 | 工程蓝纸 + 白卡片 + 精密边线 | 产品、增长、商业模型、工具说明 |
| 紫线 | 浅灰画布 + 一条紫色判断线 | 项目复盘、产品判断、团队 memo |
| 墨线 | 黑白极简 + 极细墨线 | 技术短文、发布说明、工程笔记 |
| 陶土 | 奶油纸底 + 陶土色批注 | AI 研究、方法论、温和解释 |
| 宣纸 | 纸白柔灰 + 淡黄重点 | SOP、清单、资料整理、轻教程 |
| 朱批 | 新闻纸底 + 红笔顶线批注 | 商业判断、趋势分析、强观点 |

## 选择原则

- 没有明确视觉诉求时，按文章气质选择；没有明显倾向时用 `白瓷`。
- 如果文章是商业判断、趋势分析或强观点，优先 `朱批`、`杏纸`、`素纸`。
- 如果文章是 AI 研究、方法论或温和解释，优先 `陶土`、`宣纸`、`蓝图`。
- 如果文章是产品、工具、技术或发布说明，优先 `蓝图`、`墨线`、`霓虹`。
- 如果文章是个人记录、随笔、金句或轻教程，优先 `金箔`、`竹简`、`青笺`。
- `青笺`以正文左对齐黑字为主，只把关键重点做浅绿底强调。
